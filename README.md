# modm-data tools

Tools that use the data generated by [modm-data](https://github.com/modm-io/modm-data):
the interactive pages of [data.modm.dev](https://data.modm.dev). modm-data generates
the data in a stable format, the tools here only read it.

| Page | Source | Data from modm-data |
|------|--------|---------------------|
| [SVD Register Explorer](https://data.modm.dev/svd/) | `web/svd/` | `header2svd`: `svd/*.svd`, `svd-files.json` |
| [Peripheral Variants](https://data.modm.dev/variants/) | `web/variants/` | `svd2variants`: `variants.json`, per variant JSON |
| [Board Pinouts](https://data.modm.dev/boards/) | `web/boards/` | `html2pinout`: `nucleo.json` |
| [Pin Mapping](https://data.modm.dev/pinout/) | `web/pinout/`, `templates/pinout/` | `pinout`: renders the templates, `data/`, `manifest.json` |
| [Clock Solver](https://data.modm.dev/clocks/) | `web/clocks/` | `site/export.py`: `data/`, the Python clock code in `py/clocks/` |

The pages are plain HTML, CSS and JavaScript without a build step. `web/` has the same
layout as the homepage, so `make build-homepage` in modm-data copies it over the
generated data with `cp -R web/. docs/src/`, and renders the pinout pages with
`python3 -m modm_data.pinout --templates templates/pinout`.

## Development

Generate the data in a modm-data checkout next to this repository (all of it with
`make build-homepage`, or only the part you need), then serve the pages on top of it:

```sh
python3 serve.py ../modm-data/docs/src
```

Pages in `web/` take precedence over the files in the data folder, so edits show on reload.
